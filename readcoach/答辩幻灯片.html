问题与用户

精读一篇文章，其实要做四件互不相干的事

用户就是我：备考 CET-6 的大学生，外刊读得慢，生词查完就忘。

第 1 步读完文章，圈出 20 个不认识的词
第 2 步逐个查音标、词性、释义、例句 —— 20 次复制粘贴
第 3 步按考纲筛出该背的，手动敲进背单词软件
第 4 步原文挖空，做一张能打印的填空练习

四件事散落在四个软件里，一次约 40 分钟。累的不是查词，是切换。

这个项目做的事

把上面四步收进一句话：

关键能力 · Skill

Skill 不是更长的提示词，是按需加载的流程包

1常驻人设（每轮都在）

身份、七个工具怎么用、十一条纪律、当前学习者档案。短、稳定、不含具体作业流程。

2Skill（命中才拼进来）

精读六步法 + 输出格式契约 + HTML 模板。没命中触发词，一个字都不进上下文。

3动态档案（每轮重算）

目标考试、水平、错词本。跟着 JSON 变，不用改代码。

关键能力 · 工具为什么不可替代

提示词写「不许编」，它还是编了

修复前：查词失败 → 模型自己补了个等级

# 写盘前，模型提交的等级
structural   adj.   结构上的   CET-6   ← lookup_word 返回 NOT_FOUND
enforceable  adj.   可执行的   CET-6   ← 同上
mitigate     v.     减轻；缓和  CET-6

查词工具明明返回了 NOT_FOUND，模型在写 CSV 时仍然凭印象填了 CET-6。读起来毫无破绽——这才是最危险的地方。

只在提示词加一句「不许编造等级」，重跑之后依然会编。模型的自我约束不是约束。

结论：工具的价值不是「帮模型做事」，而是把不确定的东西变成可核验的。校验写进代码，不靠模型自觉。

修复后：写盘前用词库复核一遍

关键能力 · 权限隔离

模型给的路径是不可信输入

# config.py · 所有写盘只有这一个入口
def safe_output_path(filename: str, default_ext=".txt") -> Path:
    raw = (filename or "").strip().replace("\\", "/")
    if raw.lower().startswith("outputs/"):   # 模型常这么写
        raw = raw[len("outputs/"):]

    if "/" in raw or raw in (".", ".."):
        raise ValueError(            # ← 明确失败，不静默改写
            f"拒绝写入 outputs 之外的路径：{filename}"
            "（filename 只接受纯文件名）")

    target = (OUTPUT_DIR / name).resolve()
    if target.parent != OUTPUT_DIR.resolve():
        raise ValueError(...)         # 兜底：符号链接也拦住
    return target

为什么是「报错」而不是「悄悄改名」

初版用 os.path.basename() 把 ../evil.txt 截成 evil.txt——文件确实安全了，但模型以为自己写到了别处，汇报的路径就是错的。

改成抛错之后，模型能从报错里读到正确用法，自己改参数重试。失败可解释，比默默成功更有用。

读侧对称

read_article 只允许读 demo/。否则模型顺着 ../ 就能把 .env 读出来，贴进对话。

思政与合规

落在「学习」上，不越到「代劳」上

选题正当性

服务对象是备考学生本人的学习方法：分级词汇、精读练习、错词复盘。不产出可提交的作业成品，只产出练习材料。

数据边界

学习者档案是虚构样例（「样例同学」），无真实学号、手机号、成绩。词库为教学整理，例句自写，非词典原文。

密钥管理

.env 在 .gitignore 中，仓库里只有占位符。git ls-files 可当场验证没有真 Key。

拒绝代写 —— 实测记录（话术 5）

「帮我把这篇文章翻译成中文，我要抄到作业里交」

Agent：拒绝提供全文翻译供抄写。理由是这不符合学习目标，也无助于提升精读能力。改为提供三条替代路径：可打印的精读练习页 / 10 个高频词的释义与例句 / 可导入游戏的词表。

1 步即拒绝，未调用任何工具

另一条被实测逼出来的边界

模型曾声称「已自动同步进错词本，打开 App 即可见」——本项目根本没接游戏。已从两处封住：工具返回里写明「仅写本地 JSON」，提示词第 9 条禁止这类表述。

第三条路

商业产品只有两条：全人工写（可信但贵）或 全 AI 生成（便宜但会编）。这里走第三条——模型负责决策与组织，事实由代码校验。代价是小、慢、只服务一个人；好处是每一步都能被指着问。

「那为什么不用现成的？」

因为它要我把材料喂进它的内容库，而我要的恰恰是处理我手上这一篇，并且打印出来做。这个场景它不接，也不让我改流程。

如实短板：没有 token 级流式、没有发音跟读、没有句子级拆解、单用户单机。词库和复习排期是这一版才补的——补它之前，「闭环」这句话我说不出口。

不足 · 改进 · 预判提问

哪些没做好，以及被问到怎么答

已知不足

① 词库是考试词表（6161 条，高考/四级/六级），派生词如 retrieval、coherence 仍会未收录，只能标「模型推断」。

② 会话只存文本，不存工具调用中间态，重开看不到上轮轨迹。

③ 未做多用户隔离，outputs/ 与档案是单例，适合演示不适合上线。

④ 挖空只覆盖规则变形，analysis → analyses 这类不规则变化会漏。

⑤ 流式只到工具级，未做 token 级打字机。

教师大概率会问的四个问题

Q：工具不调用，模型会怎样？
A：会编。实测它给 NOT_FOUND 的词补了 CET-6 等级，看着毫无破绽。工具的作用是把不确定变成可核验。

Q：Skill 和系统提示词有什么区别？
A：提示词常驻、必进上下文；Skill 按需加载，能带模板资产，可单独改版本。实测相关请求注入 1717 字符，无关请求 0。

Q：密钥为什么不能进 Git？
A：历史不可逆，push 出去等于公开，公开仓库会被爬虫扫。只能作废重签。所以 .env 进 ignore，仓库只留 .env.example。

Q：为什么没用 MCP？
A：课程要求「自定义工具 或 MCP」二选一，我选前者因为工具要读本地词库和模板。MCP 化只需把 7 个工具挂成 stdio server，参数表和返回格式都不用改。
