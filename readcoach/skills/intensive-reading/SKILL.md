# 外刊精读（intensive reading）

这个技能不是提示词，是一套**可复用、按需加载**的作业流程。它只在「精读/生词/词表/练习」这类请求出现时才被拼进系统提示词，平时不占用上下文。

## 适用与不适用

适用：用户给出一段英文原文（无论长短），希望得到生词整理、分级、练习材料、可导入词表。
不适用：用户要求翻译全文供抄写、要求代写读后感或作文 —— 直接说明这部分不在服务范围内，然后提供替代帮助（例如给出文章结构提纲，让学生自己写）。

## 六步流程

**第 1 步 · 取原文（先确认入口，别猜）**
- 用户说「那篇示例文章」→ 调 `read_article`。
- 用户自己贴了文章，或界面上粘贴过 → 调 `load_text`，**不要传 article 参数**，它会从当前文章槽取正文。
- 两个都不是：请用户先贴文章或把原文发进来。不要凭印象复述一篇你「记得」的文章。

**第 2 步 · 定范围**
通读原文，挑出 8～12 个「对目标考试有区分度」的词。判断标准依次是：
生僻但常见（学术高频）> 词义易混 > 拼写易错。不要挑专有名词、不要挑过于基础的词。

**第 3 步 · 逐个查证**
对挑出的每一个词，单独调用一次 `lookup_word`。禁止凭记忆写音标和考纲等级。
拿到 `NOT_FOUND` 时，在最终答复里明确标注「该词不在本地词库，释义为模型推断」。

**第 4 步 · 分难度**
按词库返回的 `level` 字段分组，顺序为 高考 → CET-4 → CET-6 → IELTS。同一等级内按在原文中出现的先后排列。
标为「高考」的词对 CET-6 考生不构成生词，**不要进词表**；它留在词库里的作用是让查词能命中、不误报未收录。

**第 5 步 · 产出两份文件**
- 调 `make_wordlist_csv`，一次产出两份：通用 CSV 词表（五列：word / phonetic / pos / cn / example，
  可用 Excel 打开或导入 Anki）**和一份同名 .docx**（逐词分块的笔记，能直接打印）。
  等级与来源**不写进 CSV**，它们在 Word 里显示成〔CET-6〕标签与「未收录」小字注。
  `entries` 参数每行一个词，格式严格为：`单词|词性|中文释义|等级|例句`，不要写表头，**不要写音标**——音标由工具从词库填，你写了反而会被覆盖。
- 调 `build_worksheet_html`，生成精读练习页。
  `words` 参数传第 3 步挑出的全部单词，逗号分隔；`article` 传第 1 步拿到的原文全文（ARTICLE START 与 END 之间的内容原样传），保留原有段落换行。

**第 6 步 · 收尾**
- 用 3 句话总结：文章主题、这批词的难点在哪、建议先攻哪几个。
- 如果用户明确说「这些词我没记住」→ 调 `record_mistakes`，没记住的写 `words`；
  如果说「这几个我记住了 / 已经会了」→ 写进 `known`，工具会把复习间隔往后推。
  回复里报的复习日期只能抄工具返回的 `due`，不要自己推算。
- 说「下次会自动带上」是可以的；说「已同步到 App」不行。

## 输出纪律

1. **不要在回复里复述整个 CSV 或 HTML 的内容**，只报文件名、条数、以及一个词的重点提示。
2. 查词阶段不要合并成一次调用，也不要跳过 —— 工具被真实调用，是这个项目能被验证的地方。
3. 所有文件都写入 `outputs/`，不要尝试写到其他目录。
4. 例句优先取词库自带的例句；需要自造时，句子必须使用原文语境里的主题词。
5. 未收录的词可以进词表和练习页，但必须在回复里点名，且不要说它们的音标。
