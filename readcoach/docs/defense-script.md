## 上台前先立一个"人话版"的心智模型

如果听众（和老师）对"智能体"只有模糊印象，你整场讲的其实是这一句：

> **聊天机器人只会「说」；智能体多了一双手——它能真的去查、真的去写文件，做完把结果拿回来接着干。**

这句话下面的一切技术名词，都可以顺着这个比喻讲下去：

| 术语 | 一句人话 |
|---|---|
| 工具（tool） | 助手手里的字典、计算器、打印机。模型自己不会查也不会写，它只能"点名"让程序去做。 |
| 工具调用 | 助手说"我要查 mitigate 这个词"，程序去查，把**真结果**递回来。 |
| LangGraph 状态图 | 一张只有两个框的流程图：「想」和「做」来回走，走到它觉得能回答了为止。 |
| 系统提示词 | 员工的岗位说明，天天贴在墙上，每轮都在。 |
| Skill | 一本按需翻开的作业手册，说到"精读"才拿出来。 |
| 权限隔离 | 门禁卡：只给两张，一张进 demo，一张进 outputs。 |
| 词库校验 | 交卷前拿标准答案对一遍，答案上没有的，就写"没查到"，不许自己填。 |
| 语种注册表 | 一张"每个语种怎么考、怎么注音、查得到查不到"的对照表，加语种 = 加一行。 |
| 每日推送三级回落 | 送报的三级预案：今天的先看柜里，没有就去楼下拿，再没有就用昨天存的那份。 |
| 复习排期 | 错题本自己算好下次哪天见你，模型只是把日期念出来。 |

**这十行背下来，全场不会有你答不上的问题。**

## p2 ｜问题与用户　⏱ 26″

**① 这页只讲一件事**：我要解决的不是"查词慢"，是"四件事在四个软件之间来回切"。

**② 先想明白**
这页决定老师信不信你这个题目值得做。所以别讲功能，讲**你自己的痛**。
为什么强调"切换"？因为如果痛点是"查词慢"，那有道词典就解决了，你的项目没有存在理由。痛点在"这四步串不起来"，才需要一个会自己排步骤的东西——这是你后面所有设计的根。
四步是哪四步，一定要数出来，一根手指一步，听众才跟得上。

**🎤 照念**
> 先说为什么做。我自己在备考六级，精读一篇外刊要做四件事：
> 圈出生词、一个个查音标释义、按考纲筛出该背的、再把原文挖空做成练习页。
> 四件事在四个软件里，一次四十分钟。
> **真正累的不是查词，是来回切换。**
> 所以我要的不是一个聊天框，是能把这条链一次跑完、还留下文件的东西。

**➕ 可以加（+8″）**
> 换句话说，我缺的不是工具，是一个"帮我把工具串起来的人"。

**⌫ 计时紧可删**：「四件事在四个软件里，一次四十分钟。」

**👉 动作**：数四步时伸四根手指，一步一根。最后一句放慢。

## p3 ｜总体架构　⏱ 32″

**① 这页只讲一件事**：这四个框不是画着好看，每一个都在解决一个具体问题。

**② 先想明白**
老师看架构图，看的是"你是不是抄的模板"。所以不要从上到下念标签，要念**为什么需要这一层**：

- 为什么要有界面？因为用户只会说中文，不会写 JSON。
- 为什么要有那个"来回走"的循环？因为一件活要拆成十几步，没人能一次想全，得走一步看一步。
- 为什么强调"七个工具我自己写的"？这是课程要求的得分点，也是"模型编不了"的物理基础。
- 为什么提 OpenAI 兼容端点？证明你不是把某家 SDK 焊死，换模型只改两行——工程素养。
- 为什么专门指那条虚线？这是全场第二个得分点（p7 会展开），先埋个钉子。

**🎤 照念**
> 结构四层，从上往下。
> 最上面是界面，用户只说一句中文。
> 中间是 LangGraph，一张流程图：它想一下、决定叫哪个工具；工具去做，把结果交回来；来回走，直到它觉得可以回答了。
> 下面挂三样东西：七个我自己写的工具、一个 Skill、一份本地档案。
> 模型是百炼的 qwen-plus，走 OpenAI 兼容接口，所以换模型只改环境变量两行。
> 最左边这条虚线是**门禁**：读只能读 demo 目录，写只能写 outputs 目录。

**➕ 可以加（+10″，全场加分项）**
> 这里有个容易被忽略的点：模型本身既不会查字典，也不会写文件。它唯一能做的是"发指令"。所以文件里的每个字是谁写的，事后可以查。

**👉 动作**：手从上往下点四层，最后停在虚线上不动，说"门禁"两个字。

## p4 ｜关键能力 · 主路径　⏱ 34″

**① 这页只讲一件事**：这十二次调用是模型自己排的，我一个字都没写死。

**② 先想明白**
这是全场最容易被误读的一页。如果老师说"哦，你写了个脚本按顺序调工具"，你这门课的分就没了。
所以三件事必须说清楚：

1. **顺序不是我写的**——我只给了它工具清单和一句话，顺序是它现场决定的（同一句话跑两次，中间步骤都可能不一样）。
2. **它会自己纠错**——猜错文件名→工具明确报错→它自己改参数重来。这是"智能体"和"if-else 脚本"最直观的分界线。
3. **它最后那句"有词没收录"不是我教的**——是工具的返回值里带着这个事实，它照着念。**说法的可信度来自文件，不是来自模型的人品。**

**🎤 照念**
> 这是一句话的真实轨迹，不是我写死的流程。
> 它先读原文——第一次文件名猜错了，工具回它"不存在，可用的是这个"，它自己改参数重来。
> 然后查了八次词，一次一个。再写词表——**CSV 和排好版的 Word 笔记是一步落盘的**——再生成练习页。
> 一共**十二次工具调用、二十多步、四十到五十秒**。
> 最后它主动说：有几个词词库里没有，建议核对权威词典。这句话也不是我教的，是工具返回里带出来的。

**➕ 可以加（+10″）**
> 界面上这些步骤是一条一条展开的，工具名、参数、返回的前几十个字都看得到——也就是说，老师可以当场确认是工具在算，不是模型在说。

**⌫ 计时紧可删**：「然后查了八次词，一次一个。」

**👉 动作**：说到"猜错文件名"时手指点屏幕上"自纠"那一行；说"不是写死的"时摇头一次——这个动作比形容词有用。

## p5 ｜关键能力 · Skill　⏱ 24″

**① 这页只讲一件事**：提示词是常驻的，Skill 是按需翻开的，而且能带模板。

**② 先想明白**
这是课程的核心考点之一（demo_5 讲 Skills），必须一次说清两者的区别，别绕。
最有效的讲法是"岗位说明 vs 作业手册"：岗位说明天天贴墙上（每轮都在，占着上下文）；作业手册放在抽屉里，来这活才拿出来（不占地方，还能单独改版）。
"一千七百多字符 vs 零"这组数字一定要给——**这是你实测出来的，不是抄来的定义**，老师最认这个。
最后那句"加场景只要加一个目录，Python 一行不改"，是工程上的价值：说明你的流程和代码是解耦的。

**🎤 照念**
> Skill 和提示词不是一回事。
> 提示词是常驻的，每轮都在，像员工的岗位说明。
> Skill 是一本**按需翻开**的作业手册：说到"精读"，它才把六步流程和网页模板拼进上下文。
> 我量过：问精读，注入一千七百多字符；问今天天气，零字符。
> 所以要加新场景，只要加一个目录，Python 一行不用改。

**👉 动作**：左右手各比一个位置（左=常驻，右=抽屉），说"翻"时右手做拉开抽屉的动作。手势一到位，这页 10 秒就讲完了。

## p6 ｜关键能力 · 工具为什么不可替代　⏱ 38″（**全场最重要，别赶**）

**① 这页只讲一件事**：我在提示词里写"不许编"，它还是编了；所以我把校验写进了代码。

**② 先想明白**
这是整场答辩的"啊哈"点，也是老师最想听的东西——所有老师都知道大模型会编，但**大部分学生只会说"我加了提示词"**。你多走了一步，这一步就值分。
讲这页的顺序别乱，它是一个小故事：

1. **现象**：工具明明回了"没收录"，模型照样填了"CET-6"，而且填得很像真的。
2. **第一次修复，失败**：加一句"不许编造等级"——重跑，还编。（**这次失败一定要讲，它比成功更有说服力**）
3. **第二次修复，成功**：写文件前拿词库复核。词库有 → 以词库为准；词库没有 → 写"未收录 / 模型推断"，并加一列"来源"。
4. **收束成一句金句**：模型的自我约束不算约束。

为什么"加一列来源"很妙？因为它把错误从"看不出来"变成"有据可查"。老师翻你的 CSV，一眼能看到哪几个词是推断的——**这比全对更可信**。

**🎤 照念**
> 这一页是我两周里最大的收获。
> 第一次跑，"structural"和"enforceable"这两个词，查词工具明明回的是"没收录"。
> 但模型写词表的时候，照样给它们填了"六级"，读起来毫无破绽。
> 我先在提示词里加了一句"不许编造等级"，重跑一遍——**它还是编**。
> 所以我把校验搬进代码：写文件之前拿本地词库复核。词库有，就以词库为准；没有，就写"未收录、模型推断"，再加一列"来源"。
> 结论一句：**模型的自我约束不算约束。** 工具的价值不是替模型干活，是把不确定的东西变成能核对的。

**➕ 可以加（+8″）**
> 这一列"来源"是我故意留的：错的地方得留下证据，不然我自己都发现不了。

**⌫ 计时紧可删**：最后那句"工具的价值……"（但金句"模型的自我约束不算约束"**不能删**）。

**👉 动作**：讲到"它还是编"时，停一拍，看着老师。这是全场唯一值得留白的地方。

## p7 ｜关键能力 · 权限隔离　⏱ 26″

**① 这页只讲一件事**：模型给的路径是输入，输入不可信；出错要报错，不要偷偷改名。

**② 先想明白**
这页的技术点叫"路径穿越"，但**别用这个词**，用例子讲：
模型如果说"帮我写到 ../../.env"，没有门禁就真写到外面去了。读的那一侧更可怕：顺两个点把 .env 读出来，密钥就出现在聊天记录里了。
这页的**思想**比技术更值钱：初版你用"截取文件名"悄悄改成安全路径——文件安全了，但模型以为写到了别处，**它汇报给你的地址就是错的**。改成直接报错，它反而能从错误信息里学会正确用法，自己重来一次。
一句话：**对智能体来说，"失败但说得清"比"成功但骗了你"有用。**
这句和 p4 的"自纠"是同一个思想的两次出现，讲的时候可以呼应一句"跟前面那次改文件名是一回事"。

**🎤 照念**
> 模型给的路径，也要当成不可信输入。
> 初版我把 ../evil.txt 截成 evil.txt，文件确实落在 outputs 里，安全了。但模型以为写到了别处，**汇报给我的路径就是错的**。
> 现在改成直接报错：错了就告诉它为什么错，它能自己改参数再来一次。
> 读的那一侧对称：读文章只认 demo 目录，不然顺着两个点，就能把 .env 读出来贴进对话。

**⌫ 计时紧可删（−8″）**：「读的那一侧对称：读文章只认 demo 目录……」这句可以只说"读的那一侧也是对称的"，细节留给 p12 讲合规时再说。

**👉 动作**：说"顺着两个点"时，两根手指做往上爬的动作。

## p8 ｜关键能力 · 多语种　⏱ 26″（**新增页**）

**① 这页只讲一件事**：五门语言共用一套流程，但查不到的时候它会说"不行"，不假装能查。

**② 先想明白**
这是做完主路径之后我自己最想升级的一点。讲它有两个层次，**层次比数量重要**：

第一层是**配置化**。原来代码里到处写死"CET-6"，现在我把它抽成一张语种表，每行写四件事：考纲体系、注音形态、词库覆盖、词形规矩。所以切到日语，等级列表自动变成 JLPT N5 到 N1，不是继续写六级；德语名词自动大写并带 der/die/das，法语名词带冠词。这些是外语学习者真会踩的坑。

第二层是**边界**。这一层老师最爱听：**非英语我没做本地词库，所以查词工具直接回"这个语种不支持"，词表里每条都标"模型推断"。**
这句话一定要讲透——它跟 p6 是同一个思想的延伸。p6 讲的是"英语语种里，个别词查不到"，p8 讲的是"整个语种查不到"。**同一个诚实原则，作用在更大的范围上。**
反面是什么？反面就是我可以在提示词里写一句"日语词也请给出 JLPT 等级"，模型会立刻编一堆 N2、N3 出来，看着比英语还专业——**那才是真正的害处**。

**🎤 照念**
> 这一页是我做完主路径之后最想说的一个升级：原来只能学英语，现在左侧选日语、法语、德语、西班牙语，等级列表会跟着换——切到日语就是 JLPT N5 到 N1，不是继续写六级。
> 但边界我要讲清楚：**非英语我没有做本地词库，所以查词工具会直接说「这个语种不支持」，词表里每条都标「模型推断」。我不给它编一个假的考纲等级，宁可让它说不行。**

**➕ 可以加（+10″）**
> 这跟第六页是同一个原则：模型的自我约束不算约束。我不写那句"不许编"，我让它在工具层面就查不到。

**⌫ 计时紧可删（−6″）**：第一段里"不是继续写六级"这句可以省，老师看卡片自己看得懂。

**👉 动作**：说到"宁可让它说不行"时，语气放平，不要带情绪——这是设计，不是委屈。

## p9 ｜关键能力 · 每日推送　⏱ 24″（**新增页**）

**① 这页只讲一件事**：每天开门就有一篇，而且断网也有——靠的是三级回落，不是靠运气。

**② 先想明白**
这页要打消一个老师一定会有的疑问：**你这东西每天都要联网，答辩那天网不好怎么办？**
所以讲的重点不是"能推送"，是**"推不出来也有东西"**。左边那个三级回落流程就是答案：当天缓存 → 联网抓 → 离线快照。我准备了五语种各 2–3 篇离线快照（14 篇），所以最差情况也有内容。
右边那五篇是**今天真实抓到的**，标题和字数都在页上——这是可以现场核验的，不要说"效果很好"，说"今天抓到的是这几篇"。
连续打卡天数是**按日期集合算的**：把做过的日期存成集合，今天在集合里就 +1，漏一天就断。这跟"记录一个计数器"不同——计数器漏一天不会断。这是很小的代码差别，但体现了对"打卡"这件事的理解。

**🎤 照念**

> 右边是今天的真实结果，五个语种各抓到一篇，右下角是连续打卡天数——按日期集合算的，漏一天就断。

**➕ 可以加（+8″）**
> 为什么用日期集合不用计数器？因为计数器漏一天不会断，集合会。这是个很小的代码差别，但我一开始就想清楚了。

**⌫ 计时紧可删（−6″）**：「右边是今天的真实结果」这半句可以省（页上有表）。

# 三、提问预案（2 分钟）

## 必答四题（p15 上已写，背下来）

**Q1 工具不调用，模型会怎样？**
> 会编。实测它给"没收录"的词补了六级等级，看着毫无破绽。所以我把校验写进工具，不靠提示词。

**Q2 Skill 和系统提示词有什么区别？**
> 提示词常驻，每轮都在；Skill 按需加载，还能带模板、能单独改版本。实测相关请求注入一千七百多字符，无关请求零。

**Q3 密钥为什么不能进 Git？**
> 历史删不掉，push 出去就等于公开，公开仓库有爬虫分钟级扫 key，只能作废重签。所以 `.env` 进 ignore，仓库只留 `.env.example`。

**Q4 为什么没用 MCP？**
> 课程要求"自定义工具 或 MCP"二选一，我选前者，因为工具要读本地词库和模板。MCP 化只要把它们挂成 stdio server，参数表和返回格式都不用改。

## 大概率追加的六题

**Q5 这段代码是谁写的？为什么这样设计？**（必被问，指 `tools/wordlist.py` 的 `_verify`）
> 我写的。起因是实测到模型编造等级，所以把"词库是否收录"做成写盘前的硬校验：收录就以词库为准，没收录就标"未收录"并记来源。这样模型即使想编，文件里也留不下痕迹。

**Q6 你怎么知道模型在编？**
> 因为我每次都把工具真实返回和最终回复对一遍。两周抓到十几处：编考纲等级、说 CSV"含音标"（文件里没这列）、说"已同步进 App"（根本没接）、报错词次数慢一格、把输入格式当输出格式（说 CSV 用竖线分隔）。

**Q7 换个场景还能用吗？**
> 能，只要换一个 `SKILL.md` 目录。工具是通用的（查词、写表、生成页面、记错词），流程写在 Skill 里。

**Q8 为什么用 LangGraph 而不是 while 循环？**
> 状态图能直接当架构图讲，工具循环、中断、步数上限都是框架给的。代价是要懂 `recursion_limit`——我在这里踩过坑：一次工具调用占两步，主路径要二十步以上，我一开始设在 15，界面上就只显示半截轨迹、回复也不进会话。

**Q9 下次复习的日期是你编的吗？**
> 不是。`record_mistakes` 里自己算的：答错就把间隔归 1 天、难度系数减 0.2；答对按 1 天 → 3 天 → 上次 × 系数往后推。日期同时写在档案里、也放在返回值里交给模型，提示词明令只能抄这个字段。这是简化版 SM-2，只有两档结果，没有 Again/Hard/Good/Easy 四档评分。

**Q10 词库多少条？为什么还有词没收？**
> 六千一百六十一词，高考、四级、六级三档。派生词（比如 retrieval、coherence）不在词表里，就会标"未收录"。这是考试词表的边界，下一步接真实词典 API 才能解决——我把它写在不足里，没有藏。

**Q11（新增）日语、法语这些，为什么不能也查词？**
> 因为本地词库我只做了英语一门，6161 条。其他语种我在工具层面直接回"这个语种不支持"，词表每条标"模型推断"，Word 笔记顶部也写一行说明。要补是逐门往词库里加，成本是一条条标考纲等级和音标——这是活儿量问题，不是流程问题，流程五门语言已经共用同一套了。

**Q12（新增）每天推送靠什么源？会不会挂？**
> 走新华网的五个语种版，各语种正文容器一样，所以抓取逻辑只有一份。会挂——所以有三层：当天缓存、联网抓、离线快照，我都抓了 14 篇存着，断网也能推。抓取依赖对方页面结构，这是已知不足，页面上写了。
