# 3 分钟演示录屏 · 分镜与逐字稿

用途：现场演示失败时的兜底（教师明确允许播 3 分钟以内录屏，但现场分会略低）。
建议在 **10/25 前**录好一版，之后如果代码有改动，只在改到主路径时重录。

---

## 一、录制前 5 分钟的准备

```bat
cd /d D:\readcoach
.venv\Scripts\python scripts\reset_demo.py
.venv\Scripts\python -m streamlit run app.py
```

- [ ] `outputs/` 已清空（`reset_demo.py` 会做）
- [ ] 浏览器窗口宽度调到 1440 以上，侧边栏展开
- [ ] 关掉微信 / QQ 的弹窗通知（录屏里弹一条就废了）
- [ ] 输入法切到英文，避免演示中途冒出候选框
- [ ] 分辨率固定，录制期间不要拖动窗口

录制工具：`Win + G`（Xbox Game Bar，系统自带，录当前窗口）或 OBS（录屏幕 + 麦克风）。
**一定要录麦克风**，光看操作没声音，教师会给更低的分。

## 二、分镜表（总长 2:50，留 10 秒余量）

| 时间 | 画面 | 你在说什么（逐字稿，可直接念） |
|---|---|---|
| 0:00–0:15 | 项目根目录 + `README.md` 打开 | 「这是外刊精读教练。丢一篇英文原文进来，它自己查词、分级、出词表、出挖空练习页。路径 A，LangGraph + 百炼 qwen-plus。」 |
| 0:15–0:30 | 浏览器里 Streamlit 首页 | 「界面只有三块：对话区、侧边栏的学习者档案、产物下载。界面层不写业务逻辑，只负责把工具调用过程显示出来。」 |
| 0:30–1:50 | 输入主路径话术，回车 | 「一句话：帮我精读 demo 里那篇校园碳排的文章，挑出 8 个 CET-6 生词。」 |
| 0:35–1:30 | **工具调用逐条滚出**（关键镜头） | 「它先调 read_article 拿到原文 —— 注意这个工具只能读 demo 目录，读不了 .env。然后一个一个调 lookup_word，八次。这一步很关键：释义和考纲等级全部来自工具返回，不是模型凭记忆写的。」 |
| 1:10–1:30 | 滚到 `NOT_FOUND` 那几行 | 「structural、enforceable 这类派生词不在本地词库里，工具返回的是 NOT_FOUND，不是编一个。所以后面 CSV 里它们会被标成未收录、音标留空。」 |
| 1:30–1:50 | 回复出现 | 「四十多秒跑完，两次汇总调用：一次写 CSV（同时排好一份 Word 笔记），一次生成练习页。」 |
| 1:50–2:15 | 点开 CSV 下载 / 预览 | 「CSV 五列：单词、音标、词性、释义、例句。音标那列是工具从词库填的，模型碰不到——这样它没机会编音标。utf-8-sig 编码，Excel 双击不乱码。等级和来源我没塞进表里，它们出现在 Word 那份的标签上。」 |
| 2:00–2:20 | 打开同名 .docx（**新镜头，值得留**） | 「同一个工具顺手排了 Word：序号、单词、音标、释义、用法逐行分开，未收录的词带一行小字说明来源。CSV 是给 Excel 和 Anki 的数据，Word 才是能打印的笔记——这两个文件的分工，是用户反馈逼出来的。」 |
| 2:15–2:35 | 打开练习页 HTML | 「练习页把原文里的目标词自动挖空，包括 emissions、mitigated 这种变形，一共 8 处。」 |
| 2:35–2:45 | 输入边界话术 | 「再试一条：帮我把这篇文章翻译成中文，我要抄到作业里交。」 |
| 2:45–2:55 | 拒绝回复出现 | 「它拒绝，并给出替代方案。边界是写进提示词和工具里的，不是临场判断。」 |
| 2:55–3:00 | 停在这一帧 | 结束。不要加音乐，不要加片头。 |

**掐掉的部分**（3 分钟装不下，别硬塞）：长期记忆、错词本写回、selftest。
这三项现场口头讲一句就行，或者放到 PPT 里。

## 三、录制后自检

- [ ] 时长 ≤ 3:00（教师明确要求「3 分钟以内」）
- [ ] 全程能听清人声，没有键盘敲击盖过说话
- [ ] **画面里没有出现 `.env` 内容**、没有出现完整 Key
- [ ] 工具调用过程清晰可读（缩放到 100% 以上再看一遍）

## 四、如果只能录一次，优先保证这两段

1. **工具调用滚动的那 50 秒** —— 这是教师判断「工具是不是真被调用」的唯一证据。
2. **边界拒答的那 10 秒** —— 思政部分是评分项，也是最容易被追问的地方。

其它都可以砍。
